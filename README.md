# Сложно сосредоточиться

Адаптивный лендинг о том, почему нам сложно сконцентрироваться и как с этим справиться. Проектная работа курса «Фронтенд-разработчик» Яндекс Практикума.

## Что сделано

- Mobile First вёрстка с брейкпоинтами 768px и 1024px, «резиновая» между ними.
- Тёмная и светлая цветовые темы: автоматически по `prefers-color-scheme` и принудительно кнопками «День», «Авто», «Неон».
- Все цвета, размеры и отступы вынесены в CSS-переменные.
- Сетка страницы и галереи построена на CSS Grid.
- Адаптивный заголовок через `clamp()`, фиксированный фон страницы, «ленивая» загрузка картинок галереи.

## Технологии

HTML5, CSS3 (Grid, Flexbox, custom properties, media queries).
